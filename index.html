Belum punya file?

Unduh template, isi daftar tamu Anda, lalu impor kembali di sini.

Kolom di atas mengikuti struktur template impor (name, group, category, guest_count, session). Bila jumlah tamu lebih dari 1, baris keterangan (mis. "beserta keluarga") otomatis ditampilkan untuk tamu itu — atur teksnya di bagian Format Teks Stiker.
#NamaGroupCategoryJmlSession
Belum ada tamu. Impor file Excel/CSV di atas, atau tambahkan tamu satu per satu dengan tombol di bawah.

Aktifkan Mode uji coba untuk mengisi satu lembar penuh dengan nama acak dan menampilkan garis tepi tiap label, tanpa mengubah daftar tamu Anda — cocok untuk cek posisi di kertas biasa sebelum pakai kertas stiker asli. Cetak atau unduh PDF seperti biasa, lalu matikan mode ini.

Tombol Cetak tidak merespons, atau ukuran kertas di dialog cetak tidak sesuai (sering terjadi di HP Android)? Gunakan tombol Unduh PDF — ukurannya presisi di perangkat apa pun, lalu cetak file PDF tersebut dari aplikasi/printer Anda.

Data tamu diproses sepenuhnya di peramban ini — tidak diunggah ke server mana pun.
